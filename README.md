# Content HQ การเงิน

ระบบ "ทีมการตลาด AI" ส่วนตัว สำหรับครีเอเตอร์สายการเงิน/ประกันชีวิต ทำงานบน Claude
แทนทีมการตลาด: เขียนสคริปต์ TikTok, เขียนโพสต์ Shopee Affiliate และตรวจสุขภาพการเงินลูกค้า

## ฟีเจอร์ (เวอร์ชัน 2)

| ส่วน | ทำอะไร |
|---|---|
| **ภาพรวม** | Dashboard สไตล์ Glass: ความคืบหน้าวันนี้ งานถัดไปพร้อมนับถอยหลัง กราฟ 7 วัน สถิติต่อเนื่อง และ QR ลิงก์ฟอร์มลูกค้า |
| **งานวันนี้** | สร้างสคริปต์ TikTok 1 คลิปตามหัวข้อประจำวัน (หมุน 7 หัวข้อ) + โพสต์ขายของ Shopee 3 ช่วงเวลา (11:00 / 17:00 / 19:30) เขียนจาก Pain Point ของลูกค้า มี 3 เวอร์ชันต่อสินค้า |
| **กันซ้ำ** | เก็บคลังสิ่งที่ใช้แล้ว แล้วส่งให้ AI เลี่ยงหัวข้อซ้ำใน 30 วัน และใช้สินค้าซ้ำได้หลัง 14 วัน |
| **Financial Health Check** | คำนวณ 7 อัตราส่วนทางการเงิน คะแนนรวมเต็ม 100 จุดเสี่ยง 3 ข้อ แผน 30/90/365 วัน และข้อความสรุปส่ง LINE |
| **ฟอร์มลูกค้า** | [เปิดฟอร์ม](https://satienpongkham-art.github.io/content-hq/) ดีไซน์พาสเทลแบบทีละขั้น 6 ขั้น ผลเป็นคะแนน กราฟเรดาร์ และแผน คำนวณในเบราว์เซอร์ ไม่เก็บข้อมูล ส่งผลทาง LINE เมื่อลูกค้ากดเอง |
| **AI แสดงความคืบหน้าสด** | เห็นข้อความที่ AI กำลังเขียน และกดปรับได้ทันที เช่น “ตลกขึ้น” “สั้นลง” “ขายแรงขึ้น” |

## โครงสร้าง

```
src/
  fhc-core.js      สูตรคำนวณ FHC + ฟอร์ม (ใช้ร่วมกัน 2 หน้า)
  hq.css           ธีม Glass Dashboard ของหน้า HQ
  hq.html          หน้า HQ บน claude.ai (Artifact: ใช้ Claude ผ่าน sample, ใช้ db เก็บข้อมูล)
  fhc-public.html  ฟอร์มลูกค้า (ธีมพาสเทล ทีละขั้น)
build.py           รวมไฟล์ → dist/hq.html, docs/index.html และ gas/Index.html
gas/Code.gs        Apps Script: เสิร์ฟฟอร์ม + บันทึก lead ลง Google Sheet
instructions/      Project Instructions ของทีมการตลาด AI
```

## ฟอร์มลูกค้า: Google Form แบบมีคะแนน

รัน `createFhcForm()` ใน Apps Script (ผูกกับชีต FHC Leads) ครั้งเดียว ระบบจะสร้าง Google Form แบบ Quiz 12 ข้อ คะแนนรวม 100 พร้อมคำแนะนำรายข้อ ส่งคำตอบเข้าชีต และอีเมลแจ้งเจ้าของทุกครั้งที่มีคนตอบ

## (ทางเลือก) ฟอร์มเว็บแบบกำหนดเอง (Apps Script Web App)

1. สร้าง Google Sheet ใหม่ ตั้งชื่อเช่น `FHC Leads`
2. เมนู **ส่วนขยาย → Apps Script**
3. วางโค้ดจาก `gas/Code.gs` ลงไฟล์ `Code.gs`
4. กด **+ → HTML** ตั้งชื่อ `Index` แล้ววางเนื้อหาจาก `gas/Index.html`
5. **ทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่ → เว็บแอป**: เรียกใช้ในฐานะ *ฉัน*, ผู้มีสิทธิ์เข้าถึง *ทุกคน*
6. อนุญาตสิทธิ์ แล้วคัดลอกลิงก์ `.../exec` ไปวางในหน้า HQ (การ์ดฟอร์มลูกค้า → บันทึกลิงก์)

ลูกค้าที่กด “ส่งให้ที่ปรึกษา” จะถูกบันทึกในแท็บ `Leads` และมีอีเมลแจ้งเตือนถึงเจ้าของชีต

## Build

```bash
python3 build.py
```

- `dist/hq.html` → นำไปเผยแพร่เป็น Artifact บน claude.ai
- `docs/index.html` → เปิด GitHub Pages: Settings → Pages → Branch `main` / โฟลเดอร์ `/docs`

แก้ชื่อและ LINE ของที่ปรึกษาได้ที่ตัวแปร `ADVISOR` ใน `src/fhc-public.html` แล้ว build ใหม่

## เกณฑ์ Financial Health Check

| ด้าน | สูตร | คะแนนเต็ม |
|---|---|---|
| เงินสำรองฉุกเฉิน | สินทรัพย์สภาพคล่อง ÷ ค่าใช้จ่ายต่อเดือน (เป้า 3 เดือน, รายได้ไม่แน่นอน 6 เดือน) | 20 |
| DSR | ค่างวดหนี้ทั้งหมด ÷ รายได้ | 20 |
| หนี้บริโภค | ค่างวดบัตร/สินเชื่อส่วนบุคคล/ผ่อนของ ÷ รายได้ | 10 |
| อัตราการออม | เงินออม+ลงทุน ÷ รายได้ | 15 |
| หนี้สินต่อทรัพย์สิน | หนี้รวม ÷ ทรัพย์สินรวม | 10 |
| ความคุ้มครองชีวิต | ทุนประกัน ÷ (หนี้ + ค่าใช้จ่ายผู้ที่ต้องดูแล + ค่าใช้จ่ายสุดท้าย) | 15 |
| ความคุ้มครองสุขภาพ | วงเงินผู้ป่วยในต่อปี / สวัสดิการ / โรคร้ายแรง | 10 |

ระดับ: 80+ แข็งแรง · 60–79 พอใช้ · 40–59 ต้องดูแล · ต่ำกว่า 40 วิกฤต

> ผลประเมินเบื้องต้นเพื่อการศึกษา ไม่ใช่คำแนะนำการลงทุน
